# Graphs Assignment 2

Python project for UBB Graph Algorithms practical work no. 2.

What is included:
- the lab 1 graph ADT, extended for directed and undirected graphs
- forward BFS shortest path
- backward BFS shortest path
- connected components with DFS
- connected components with BFS
- manual execution files and sample graphs
- a scriptable report for the large graph path queries

Run the console:

```bash
cd pythonProject
python -m src.main
```

Run the tests:

```bash
cd pythonProject
python -m unittest discover -s tests
```
